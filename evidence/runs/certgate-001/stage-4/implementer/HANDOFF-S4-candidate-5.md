## Unit rule (E-11, fail closed; `tools/claims-units.mjs` `units()`)

In README.md, DEPLOY.md and METRICS.md **every piece of text is a unit**. There are two exceptions:
- the **executable part of a line inside a fence tagged `sh`, `bash`, `shell` or `console`**;
- table **separator rows** (`|---|`). These have no text; a separator row that carries text is a normal row, and so a unit.

The units are:
- each sentence of prose and list items (including link text, image alt text, blockquotes and indented code, all of which sit inside the prose they belong to);
- each heading;
- each table row, header and body (each cell is inside its row's unit);
- each HTML comment;
- each whole-line **or trailing** `#` comment on a shell-fence line;
- **every line** of a fence with any other tag (`text`, `txt`, `plain`, `json`, …) or with no tag.

Anything not recognised falls through to prose, so it becomes a unit; there is no skip branch for unknown structure.
